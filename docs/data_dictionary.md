# GeoMet drillhole data dictionary

This dictionary describes the actual local v4 source CSV, verified against its header and QA/QC report. The source record does not state a coordinate reference system, coordinate units, datum, assay detection limits, or sample interval support.

| Field(s) | Observed role | Observed type / unit | Limitations |
|---|---|---|---|
| `HOLEID` | Drillhole identifier | Text identifier | The table has 119 distinct values; collar and downhole survey tables are absent. |
| `X`, `Y`, `Z` | Sample-centroid coordinates | Numeric; units and CRS unspecified | These are not documented collars, surveyed trajectories, or interval endpoints. |
| `Ag ppm`, `Al ppm`, `Au ppm`, `C ppm`, `Ca ppm`, `Cl ppm`, `Cu ppm`, `F ppm`, `Fe ppm`, `K ppm`, `Mg ppm`, `Mn ppm`, `Na ppm`, `P ppm`, `Pb ppm`, `S ppm`, `Th ppm`, `U ppm` | Chemical assay fields | Numeric concentrations labelled ppm in the source headers | Detection limits, assay methods, QA/QC, and economic meaning are not supplied in this CSV. |

The file contains 2,000 rows and 22 columns. The four exploratory target candidates Cu, Au, Ag, and S are present. QA/QC results, including missingness, duplicates, numeric summaries, and coordinate ranges, are generated by `scripts/initial_qaqc.py` and recorded in `reports/initial_qaqc.json`.

The CSV has no lithology, alteration, mineralization/domain, from/to interval, sample length, recovery, density, collar/survey, or assay QA/QC fields. Do not infer geological domains, true support, or resource grades from the available fields.
